# n8n Automation Portfolio

Практические проекты по автоматизации бизнес-процессов с использованием n8n, API, Webhook и интеграций с внешними системами.

## Проекты

### 01 — MyMacarons
Автоматизация работы с заказами и поддержкой клиентов через Telegram, WooCommerce и AI/RAG.

### 02 — Опрос «Помощь в опросах»
Автоматизация многошагового взаимодействия с внешней web-системой через HTTP-запросы, управление сессией и расписание.

### 03 — Пропуска на въезд транспорта
Автоматизация подачи заявки на пропуск через Webhook и интеграцию с внешней системой парковки с формированием QR-кода и результата для пользователя.

## Стек

- n8n
- REST API / HTTP
- Webhook
- JavaScript
- WooCommerce
- Telegram
- PostgreSQL / Supabase
- AI / RAG
- Docker
