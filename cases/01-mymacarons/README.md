# MyMacarons — автоматизация клиентского сервиса

## Задача

Автоматизировать клиентский сервис интернет-магазина MyMacarons и объединить работу с заказами, базой знаний и операторской поддержкой в одном Telegram-интерфейсе.

Основная цель — предоставить клиенту возможность получить информацию о заказе и ответы на типовые вопросы без ручного участия оператора, а сложные обращения передавать сотруднику поддержки.

## Решение

Разработана интеграционная система на базе n8n, Telegram, WooCommerce, Supabase и AI/RAG.

Telegram-бот выступает единой точкой взаимодействия с клиентом:

- регистрация пользователя по номеру телефона;
- получение информации о своих заказах;
- просмотр статуса, доставки и стоимости заказа;
- просмотр состава заказа;
- отправка отзывов (будущая доработка);
- обращение к оператору;
- ответы на типовые вопросы через базу знаний;
- передача диалога оператору при необходимости.

## Основные компоненты

### Telegram

Пользователь взаимодействует с системой через Telegram-бота. Интерфейс объединяет автоматические ответы, работу с заказами и передачу обращений оператору.

### n8n

n8n используется как слой интеграции и оркестрации:

* обработка входящих сообщений;
* маршрутизация запросов;
* вызов WooCommerce API;
* работа с базой данных;
* запуск RAG-обработки;
* передача обращений оператору;
* формирование ответов для Telegram.

Логика разделена на отдельные workflow и подзадачи, что позволяет независимо развивать отдельные части системы.

### WooCommerce

WooCommerce является источником данных о заказах.

Через REST API система получает информацию, необходимую клиенту:

* номер заказа;
* дату;
* статус;
* доставку;
* стоимость;
* состав заказа.

Бот не создаёт заказы — он предоставляет клиенту информацию о существующих заказах.

### Supabase

Используется для хранения данных Telegram-пользователей, сообщений и компонентов базы знаний.

### AI / RAG

Для типовых вопросов используется база знаний.

Ответ формируется на основе найденных материалов, а не за счёт свободной генерации модели. Это позволяет ограничить ответы информацией, которая была подготовлена для клиентского сервиса.

Для AI-части использовалась собственная инфраструктура с локальными моделями, что позволяет не привязывать обработку запросов к платному API внешнего LLM-провайдера.

## Операторская поддержка

Если автоматический сценарий не должен продолжать обработку обращения, пользователь переводится в режим общения с оператором.

В этом режиме сообщения направляются оператору, а автоматическая AI-обработка отключается.

Таким образом, автоматизация не заменяет оператора полностью, а разделяет обращения на автоматизируемые и требующие ручной обработки.

## Что было автоматизировано

1. Авторизация пользователя через Telegram.
2. Связь Telegram-пользователя с клиентом магазина.
3. Получение данных заказов из WooCommerce.
4. Отображение состава заказа.
5. Ответы на типовые вопросы через RAG.
6. Приём отзывов.
7. Передача обращений оператору.
8. Хранение пользовательских данных и сообщений.
9. Маршрутизация разных типов запросов внутри n8n.
